This repository contains the software artifacts generated and audited for the empirical evaluation of the default security of code generated by three of the industry's most widely used Large Language Models (LLMs) under zero-shot conditions.

## ⚠️ Security Warning
> **WARNING!** The source code contained in the `ChatGPT/`, `Claude/`, and `Gemini/` folders was generated by Artificial Intelligence and **contains intentional, unpatched critical vulnerabilities** (such as SQL injection, IDOR, RCE via file upload, and insecure configurations).
>
> This repository is intended strictly for academic and research purposes. **UNDER NO CIRCUMSTANCES** should this code be used, copied, or deployed in production environments.

## 🔬 Audit Methodology
Each module in this repository underwent a three-dimensional security analysis:
* Static Analysis (SAST): Performed using Semgrep to detect syntactic best practices, embedded secrets, and tainted data flows.
* Dynamic Analysis (DAST): Performed using OWASP ZAP on local Flask environments to validate security headers, injections, and configuration flaws.
* Manual Penetration Testing: Business logic audit to identify architectural flaws (IDOR, BOLA, and authentication bypass) that evade automated scanning.
The findings were taxonomically classified using the OWASP Top 10:2025 and CWE, and scored using the CVSS v4.0 system.
## 🚀 Local Deployment (Lab Environment)
If you wish to set up any of the modules to replicate the audit, it is strongly recommended that you do so within an isolated virtual environment (`venv`).
*Clone the repository:
```bash
   git clone https://github.com/tu-usuario/TFM-GenAI-Security-Audit.git
   cd TFM-GenAI-Security-Audit
   ```
*Create and activate the virtual environment:
```bash
   python -m venv venv
   # Windows: venv\Scripts\activate
   # Linux/Mac: source venv/bin/activate
   ```
*Install the required dependencies:
```bash
   pip install -r requirements.txt
   ```
**Navigate to the desired module and start the Flask server:
```bash
   cd Gemini/2_API_CRUD
   python app.py
   ```
